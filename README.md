# 🤖 Inteligência Artificial & Ciência de Dados

Repositório dedicado a estudos, práticas e projetos acadêmicos na área de **Inteligência Artificial**, **Ciência de Dados** e **Machine Learning** utilizando Python.

---

## 📌 Conteúdo do Repositório

O repositório está dividido entre bases de dados e notebooks com foco prático em análise e modelagem:

| Arquivo / Projeto | Descrição | Principais Tópicos |
| :--- | :--- | :--- |
| `dataset-iris-svm.ipynb` | Classificação supervisionada sobre a base clássica Iris. | Classificação, Support Vector Machine (SVM), Métricas de Avaliação |
| `Atividade_DataScience_RaffaelBataglini6BNoturno.ipynb` | Análise exploratória e manipulação de dados de vendas. | Pandas, Tratamento de Dados, Estatística Descritiva, Visualização |
| `summit.ipynb` | Resoluções práticas e experimentações de dados/modelagem. | Análise de Dados, Modelos Preditivos |
| `Exerc cios_Python_RaffaelBataglini6BNoturno.ipynb` | Fundamentos e lógica de programação aplicada à Ciência de Dados. | Lógica em Python, Estruturas de Dados, Funções |

> **Nota:** As bases de apoio para os estudos de vendas (`vendas.xlsx`, `detalhes_vendas.csv` e `vendas_produtos.csv`) encontram-se disponíveis no repositório.

---

## 🛠️ Tecnologias e Bibliotecas

As ferramentas e bibliotecas utilizadas ao longo dos notebooks incluem:

* **Linguagem:** Python 3
* **Manipulação e Leitura de Dados:** `pandas`, `openpyxl`
* **Computação Científica:** `numpy`
* **Visualização de Dados:** `matplotlib`, `seaborn`
* **Machine Learning:** `scikit-learn`
* **Ambiente Interativo:** `Jupyter Notebook`

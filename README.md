# Inteligencia_Artificial
Repositório criado para atividades e trabalhos da disciplina de Inteligência Artificial

📚 Objetivos
- Armazenar códigos, relatórios e projetos desenvolvidos ao longo da disciplina.
- Facilitar a organização e versionamento dos trabalhos.
- Servir como portfólio acadêmico na área de IA.

🚀 Tecnologias utilizadas
- Python   
- Bibliotecas: Pandas, NumPy, Scipy, Scikit-learn
- Jupyter Notebook para experimentação
